# PoE-2-crafting-items

Помощник и планировщик крафта предметов в Path of Exile 2. Работает прямо в браузере, ничего устанавливать не нужно.

## Что умеет

1. **Предмет и цель.** Выбираете тип предмета (оружие, броня, бижутерия, самоцветы), базу и уровень предмета. Из полного списка префиксов и суффиксов этой базы
   отмечаете нужные моды и минимально приемлемый тир. Можно указать, что достаточно любых N из списка, и сколько префиксов
   и суффиксов должно остаться свободными (чтобы потом добавить мод оменом, эссенцией или сплавом).
2. **Варианты крафта.** Программа сравнивает шесть стратегий:
   - базовые валюты;
   - экзальты с оменами;
   - эссенция и экзальты (в том числе совершенные и «проклятые» эссенции, сплавы и сфера раскола);
   - алхимия и хаос (со сферой раскола);
   - очернение костями Бездны;
   - «всё доступное».

   Для каждой стратегии видно шанс успеха, среднюю стоимость, медиану и сумму, в которую укладываются 9 попыток из 10. Там же
   средний расход каждой валюты и пошаговый план. У каждого шага указан шанс удачи и что делать, если не повезло.
3. **Трекер крафта.** Вносите текущее состояние предмета из игры. Программа подсказывает следующее действие и шансы всех исходов,
   показывает ожидаемую стоимость до конца и альтернативы. Если что-то пошло не так, достаточно обновить моды, и план перестроится.
   Можно тренироваться кнопкой «Смоделировать бросок».
4. **Связь с игрой.** В игре наведите на предмет и нажмите Ctrl+Alt+C. Приложение распознаёт базу, уровень предмета и все моды
   с тирами, в том числе расколотые и очернённые. Поддерживаются английский и русский клиенты. Совет пересчитывается сразу, а журнал
   показывает, что изменилось и сколько потрачено. Способы чтения:
   - вставка Ctrl+V;
   - автоматическое чтение буфера при переходе в окно приложения;
   - помощник для Windows из папки `helper`: приложение видит каждый скопированный предмет само, даже на втором мониторе.

   Игра и её память не трогаются: используется только стандартное копирование текста предмета.
5. **Цены.** Цены с poe.ninja пересчитываются в одну валюту: экзальты, диваны или хаосы на выбор. Любую цену можно поправить вручную.
6. **Веса модов.** По умолчанию берутся веса сообщества с [Craft of Exile](https://www.craftofexile.com/weightings?game=poe2).
   Любой вес можно поправить самому или вставить JSON.

## Как открыть

**Онлайн (GitHub Pages).** Нужно один раз включить в настройках репозитория:

1. Settings → Pages → Source: **GitHub Actions**.
2. Влить эту ветку в `main`. После этого сайт соберётся сам, а цены будут обновляться каждый час.
3. По желанию: Settings → Secrets and variables → Actions → Variables → `POE_LEAGUE` = название лиги.
   Без этой переменной лига определяется автоматически.

**Помощник для Windows** (по желанию, для полностью автоматического режима): скачайте папку `helper` и дважды щёлкните
`start-helper.bat`. Пока открыто его окно, вкладка «Трекер крафта» в режиме «Помощник» видит каждый предмет, скопированный в игре.

**На своём компьютере.** Нужен [Node.js](https://nodejs.org) версии 20 или новее:

```bash
npm install
npm run dev        # откройте ссылку, которую покажет команда
```

## Как считается

- Состояние предмета сжимается до простой модели:
  - какие нужные моды уже есть;
  - какие заблокированы низким тиром того же мода;
  - сколько лишних модов на каждой стороне.
- Для этой модели точно решается задача минимальной ожидаемой стоимости (итерация Беллмана).
- На каждом шаге для настоящего предмета перебираются все разрешённые валюты и омены. Для каждого варианта считаются точные шансы
  исходов по пулу модов базы, и выбирается самый выгодный. Вариант «новая база» учитывается всегда, отсюда запасной план.
- Каждая стратегия проигрывается сотни раз (метод Монте-Карло), отсюда проценты и суммы.

## Ограничения, о которых важно знать

- **Веса модов.** В клиенте PoE 2 настоящих весов нет, там только «может выпасть / не может». Поэтому берём веса, которые
  сообщество измерило экспериментально (Craft of Exile). Для мечей, топоров, кинжалов, цепов и когтей, а также для модов лордов
  Бездны известных весов пока нет, там у всех модов одинаковый вес 1000, и абсолютные цифры приблизительные.
- Какой мод даёт каждая эссенция и каждый сплав на каждой базе, берётся из точной таблицы Craft of Exile. Если вариантов несколько
  (например, эссенция Бесконечности: сила, ловкость или интеллект), считаем, что выпадает случайный из подходящих.
- Совершенные и «проклятые» эссенции и сплавы убирают случайный мод. Считаем, что игра выбирает только такой мод, после удаления
  которого новому есть место.
- Омен строгания не входит в упрощённую модель (он зависит от точных уровней лишних модов). Его предлагает только пошаговый
  планировщик на настоящем предмете, поэтому оценка стоимости для стратегий с хаосом немного осторожная.
- Пока не учитываются:
  - Замок Хинекоры;
  - омены лордов Бездны, большего аннулирования и гомогенизации;
  - развращение, качество, сокеты и божественная сфера.
- Цены по умолчанию примерные, пока сборка на GitHub не скачает настоящие.

## Для разработчика

```bash
npm test           # тесты движка на реальных данных
npm run typecheck
npm run build      # готовый сайт в dist/
```

Структура:
- `scripts/build-data.mjs` подготавливает данные игры.
- `scripts/build-coe.mjs` импортирует из Craft of Exile веса модов и таблицу эссенций и сплавов и сопоставляет их с модами игры.
- `scripts/fetch-coe.mjs` скачивает сырые данные Craft of Exile для изучения (workflow «Fetch Craft of Exile data», запуск вручную,
  результат в ветке `coe-data`).
- `scripts/fetch-prices.mjs` скачивает цены (разбор ответа общий с приложением: `src/engine/ninja.ts`).
- `src/engine/parseItem.ts` распознаёт предмет, скопированный из игры.
- `helper/` содержит помощник для Windows, который отдаёт странице текст скопированных предметов.
- `src/engine/` содержит движок: правила валют, модель, планировщик, симуляцию.
- `src/worker.ts` выполняет расчёты в фоне.
- `src/ui/` содержит интерфейс.
